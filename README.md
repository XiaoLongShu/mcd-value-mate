# 🍟 麦麦省钱参谋 McValue Mate

一个基于麦当劳中国 MCP 的智能点餐与预算规划 Skill。

> 本项目为独立开发的参赛作品，不是麦当劳官方产品。

## 项目简介

输入预算、人数、口味和用餐方式，帮助用户查询实际可售餐品、
比较可行的组合，并利用 MCP 返回的价格和优惠信息进行预算规划。

项目的核心原则是：真实数据、预算优先、结果透明、不自动下单。

## 主要功能

- 查询指定门店的可售餐品
- 查看套餐组成与替换选项
- 查询门店可用优惠券
- 比较候选组合的实际应付金额
- 输出预算内推荐及省钱理由
- 对缺失数据、查询失败和超预算情况进行明确提示

实际可用功能取决于麦当劳 MCP 开放的工具、账户权限及门店数据。

## 目标用户

- 希望控制点餐预算的消费者
- 想比较套餐和优惠的用户
- 正在学习 AI Agent、MCP 与开源开发的开发者

## 技术方案

- 麦当劳中国 MCP Server
- 支持 MCP 的 AI 客户端
- SKILL.md 工作流说明
- Git 与 GitHub 版本管理

## 开始使用

1. 阅读麦当劳 MCP 服务规则。
2. 在 https://open.mcd.cn/mcp 申请 MCP Token。
3. 按所用 MCP 客户端的官方说明配置服务。
4. 导入或采用 SKILL.md 中的工作流。
5. 通过真实 MCP 查询餐品及价格，并验证推荐结果。

配置示例见 `mcp-config.example.json`。
该文件只含占位符，不能直接作为带有效凭证的配置使用。

## 示例需求

“预算 35 元，两个人用餐，希望比较有饮料和不含饮料的方案。
请查询当前门店的可售商品与可用优惠，计算最终价格。”

示例需求不代表当前存在符合条件的商品或优惠。
最终结果必须来自实际 MCP 查询。

## 项目结构

- `SKILL.md`：核心工作流
- `MCP_INTEGRATION.md`：MCP 集成说明
- `mcp-config.example.json`：脱敏配置示例
- `CONTEST_DECLARATION.md`：官方参赛声明
- `examples/`：测试说明及脱敏示例

## 安全与限制

- 不在仓库中保存真实 Token、密码或个人凭证。
- 不伪造实时价格、库存或优惠。
- 不自动创建订单或支付。
- 最终价格与商品供应情况以麦当劳官方渠道为准。
